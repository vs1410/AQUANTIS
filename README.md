# AQUANTIS
## A Machine Learning Framework for Water Quality Prediction

AQUANTIS is an educational ML project that explores the prediction of the `Potability` label in the commonly used Water Potability dataset. It compares four classification models, visualizes data quality and evaluation results, and provides an interactive Streamlit interface.

> **Important limitation:** this is an educational prediction system, not a drinking-water safety certification tool. A model prediction cannot replace laboratory testing or compliance with applicable drinking-water standards.

## Features
- Dataset loading and missing-value inspection
- Train/test split before fitting preprocessing steps
- Median imputation and feature scaling inside scikit-learn pipelines
- Four models evaluated on the same held-out test set
- Accuracy, precision, recall, F1, ROC-AUC, confusion matrices and ROC curves
- Interactive predictions and dataset exploration
- Exportable model-comparison table

## Dataset
The app attempts to download the Water Potability dataset from a public GitHub raw-file URL. The dataset is commonly associated with the Kaggle “Water Potability” dataset. Verify the source and its licensing before submitting or redistributing it. If the download fails, download `water_potability.csv` from a trusted dataset source and place it in `data/water_potability.csv`.

Expected columns:
`ph, Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic_carbon, Trihalomethanes, Turbidity, Potability`

`Potability` is the target label, commonly encoded as 0 or 1. The data contains missing values in some predictor columns.


## Methodology
1. Load and validate the dataset.
2. Separate predictors and target.
3. Create a stratified 80/20 train/test split.
4. Fit imputation and scaling only on training data using pipelines.
5. Train Logistic Regression, K-Nearest Neighbors, RBF Support Vector Classifier, and Random Forest.
6. Evaluate every model on the same test set.
7. Select a model based on validation evidence and task needs, not just raw accuracy.

## Reproducibility
A fixed random seed is used. Metrics are generated by `train.py` from the actual data available at run time. No performance values are hard-coded.
